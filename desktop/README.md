一个以“音程比”为核心的本地多轨编曲工具。音符之间可以使用任意正整数分数建立纯律关系，界面会显示真实频率、音分值、标准纯律音程名称和质数限连线。

## 主要功能

- 任意分数纯律音程：选择基音，输入分子、分母和方向即可建立关联音；不再受固定音程按钮限制。
- 原工程质数限图形：2 限灰、3 限红、5 限绿、7 限紫、11 限橙、13 限黄绿、17 限珊瑚，并保留各限原有的左端、右端、交叉和外弯连接方向；更高质数限使用白色中线。
- 标准中文术语：使用基音、纯五度、纯律大三度、自然七度、音分、质数限等通行术语。
- 分离式多轨工作流：多轨页只负责轨道编排；每条轨道通过明确的“钢琴窗”按钮进入独立编辑界面。
- 多轨页只画音符条，不显示音名、比例或音程连线；每条轨道可从底边单独纵向拉伸。
- 保留原作钢琴窗语言：紫灰全屏画布、白色音线、三角基音标记、质数限彩色曲线、底部悬浮运输栏与音线弹窗。
- 笔与框选工具：按住 `Ctrl` 可临时框选，`Delete` 删除整个选择集；“移动音程”会留下虚线原位音并建立新的比例连接。
- 自定义十二音吸附：可逐项设置 C 到 B 相对 C 的纯律分数，时间吸附的最小拍会直接显示为钢琴窗辅助线。
- 默认音源：`sound/PC-98 Soundfont.sf2`，新增乐器轨使用 Acoustic Piano，鼓轨使用 Standard Drums。也可逐轨选择 Salamander 钢琴、Strumstick、颤音琴、K‑Sharp、管风琴或基础合成器。
- 默认工程：“新建 → 新建默认工程”加载根目录的 `东方旧作音色预制.jidaw`，保留六条轨道及各自的 PC-98 预置。首次启动没有自动存档时也使用此工程；“新建空白工程”保留空白编曲入口。
- 多轨编曲：每条轨道独立静音、独奏、音量、音源与 SF2 预置。
- 鼓轨：与旋律轨共用框选、批量移动、首尾时值编辑、复制粘贴和撤销；点击鼓符打开力度、静音、颜色和鼓件编辑菜单。鼓垫下方可独立调整每种鼓的音量。
- 混音台：顶部“混音台”或钢琴窗右下角“≋”进入，逐轨调整电平、声像、三段 EQ（±18 dB）和自制立体声房间混响。轨道推子控制合成后的增益，SF2 力度与采样分层保持独立；播放和 MP3 导出使用同一效果链。
- 预制音源：PC-98 和 Touhou 均可从乐器轨、鼓轨的音源菜单直接选择，鼓轨优先使用 Bank 128 鼓组；重新打开工程时自动恢复。音源预置、单鼓音量和混音设置随工程及轨道码保存。
- 本地 SF2：直接选择 `.sf2` 文件并读取其中的预置；纯律频率以小数 MIDI 键值播放，不会被重新量化为十二平均律。
- 本地工程文件：保存为 `.jidaw`，记录全部轨道、音符、分数关系及 SF2 路径；再次打开时自动尝试恢复音源。
- MP3 导出：通常按 20 秒分段离线渲染，在后台线程连续编码，显示进度并支持取消；共用 SF2 采样缓存，缺失音源时会指出对应轨道。跨段持续音从原起音重建，因此极长持续音仍可能扩大单段缓冲。
- 撤销/重做与自动恢复：最多保留 100 步编辑历史，并在本机自动保存当前工作状态。

## 运行

Windows 可双击根目录或 `dist/` 中的 **`start-local.cmd`**，直接打开 Electron 桌面应用，无需 Live Server。首次运行会安装依赖；之后每次启动会构建当前源码。`dist/index.html` 是构建产物，请通过启动文件打开应用。

GitHub 仓库中的当前桌面项目位于 `desktop/`，原有网页版保留在仓库根目录。
克隆仓库后先进入 `desktop/`。可选的 `sound/Touhou.sf2` 使用 Git LFS 保存，
需要先安装 Git LFS 并执行 `git lfs pull` 获取完整文件；默认 PC-98 音源随
桌面项目一起提供。音源的第三方权利说明见 `THIRD_PARTY_NOTICES.md`。

需要 Node.js 20.19+ 或更新版本。

```powershell
npm install
npm start
```

`npm start` 会先进行 TypeScript 检查和生产构建，然后启动 Electron 桌面应用。开发界面可使用 `npm run dev`。

固定调式和自定义调律的音名均可逐项填写，随工程、调律表和轨道码保存。派生音落在当前调律格内时使用表内名称；格外派生音按完整比例链约分后的最高质因数标上标维度，例如 C 大调的 9/8 显示 D，10/9 显示 D⁵。所有音名均不显示约等于符号。

`npm run test:editor` 检查调律命名、和弦精确比例与撤销、SF2 键位及 MIDI 导出，并运行 Electron 界面与保存重载回归；截图保存到 `tests/artifacts/`。

SF2 的 Bank 128 预置自动使用打击乐编辑器，按实际采样键位显示名称、试听及调整单鼓音量。滚轮上下浏览鼓件，Shift + 滚轮横向移动，Ctrl + 滚轮缩放。

点击任意旋律音符，在频率比操作下方选择“一键和弦”的 3 / 5 / 7 / 11 限，然后点击名称与频率比添加。和弦保留精确比例、时间和力度，一次撤销即可恢复。限数表示质因数上限。

`npm run test:mp3` 会构建并运行 Electron 测试，覆盖 MP3 解码、混响与 EQ 分段接缝、SF2 增益与力度独立性、单鼓音量、鼓声低频与镲片频谱、鼓轨编辑交互、Touhou 实际加载/恢复/导出、十分钟工程的 PCM 缓冲及取消重试。界面检查截图保存在 `tests/artifacts/`。

导出窗口持续显示渲染、编码、保存阶段和用时。失败详情会保留，可直接保存日志；关闭窗口后仍可通过顶部“导出日志”保存最近一次记录。桌面端还会自动把每次导出的日志写入应用用户数据目录的 `logs/`，包含工程路径、轨道音源、阶段时间和异常堆栈。

移动工程后，桌面端会尝试工程相对路径、工程旁的 `sound/`、`assets/`、`fonts/`、`audio/` 目录及以前定位过的同名音源。若 SF2 仍缺失，在失败窗口点“重新定位 SF2”，选择一次即可恢复引用同名音源的多条轨道，并保留各轨道预置；保存工程即可保留新路径。工程文件本身不包含 SF2 采样。

## 基本操作

1. 在多轨页点击目标轨道右侧的“钢琴窗”。
2. 使用笔工具在钢琴窗空白处单击建立基音；拖动空白区域平移，滚轮缩放。
3. 拖动音线本体移动音符，拖动两端改变起始位置或时值；吸附在松开时应用。
4. 点击音线打开原式浮动菜单；“移动音程”和“从此音添加”都可选择常用比例或输入任意分数。
5. 右下角齿轮用于当前轨道的名称、音源、BPM、时间吸附、十二音比例与本地 SF2 设置。

常用快捷键：`空格` 播放/暂停，`P` 选择笔工具，`V` 选择框选工具，按住 `Ctrl` 临时框选，`Delete` 删除所选，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，`Ctrl+S` 保存，`Ctrl+O` 打开。

## 工程结构

- `src/ratio.ts`：分数约分、质数限、音分与标准音程名称。
- `src/audio.ts`：精确调律播放、逐轨音频总线、SF2 与运输调度。
- `src/app.ts`：工程模型、播放列表交互、检查器、历史和文件操作。
- `electron/`：本地窗口与安全文件桥接。

旧版 Nafchanaphata 术语、分享链接和 CDN 运行方式不再参与当前应用。
